## Домашнее задание 1: UI конвертера валют

### Цель

Сверстать страницу конвертера валют по макету и грамотно разбить интерфейс на React-компоненты. На этом этапе работаем только с UI и локальными данными.

### Стек

- `Vite`
- `React`
- `TypeScript`
- `Scss modules` для пользовательских стилей
- `Vitest + React Testing Library` для тестирования

### Данные

В первой домашке все данные должны быть статичными и прокидываться через пропсы.

### Что нужно реализовать

1. Создать свой репозиторий в GitHub и запушить туда содержимое этого репозитория.
2. Поднять новый проект на `Vite`, `React`, `TypeScript`. При установке назовите его `client`.
3. Заменить стандартные конфиги, созданные Vite при инициализации проекта, на конфиги из папки `config`.
4. Одной командой добавить в проект пакеты для Sass, Stylelint, ESLint и Prettier:

```bash
npm install --save-dev --save-exact sass@1.101.7 stylelint@17.14.1 stylelint-config-css-modules@4.6.0 stylelint-config-standard-scss@17.0.0 stylelint-order@8.1.1 stylelint-scss@7.2.0 stylelint-use-logical@2.1.3 eslint@9.39.5 eslint-config-prettier@10.1.8 @eslint/js@9.39.5 typescript@6.0.3 typescript-eslint@8.65.0 globals@17.7.0 eslint-plugin-react-hooks@7.1.1 eslint-plugin-react-refresh@0.5.3 eslint-plugin-react@7.37.5 eslint-plugin-import@2.32.0 prettier@3.9.6 npm-run-all2@8.0.4
```

5. В `package.json` в scripts добавить команды:

```json
{
  "lint": "run-s lint:*",
  "lint:eslint": "eslint src --ext .ts,.tsx",
  "lint:stylelint": "stylelint src/**/*.scss",
  "lint-fix": "run-s lint-fix:*",
  "lint-fix:eslint": "npm run lint:eslint -- --fix",
  "lint-fix:stylelint": "npm run lint:stylelint -- --fix"
}
```

6. Разобраться что за пакеты и команды.
7. Сверстать экран конвертера валют [Макет](https://www.figma.com/design/S66rvu5vtQM7zBEbSxlqou/%D0%9A%D0%BE%D0%BD%D0%B2%D0%B5%D1%80%D1%82%D0%B5%D1%80-%D0%B2%D0%B0%D0%BB%D1%8E%D1%82%D1%8B?node-id=2035-339&t=Hs7MnRBOijiOUnra-1):
   - Экраны ошибок/загрузки пока что не нужны. Их не верстаем.
   - Как будет выглядеть выпадающий список(именно его элементы) выбирайте сами. Можете использовать библиотеки или сделать сами в следующей домашке, когда будете работать с useState. Сейчас допускается, что он может быть нерабочим.
   - Вместо графика вставьте картинку из макета.
8. Визуально разбить макет на компоненты:
   - выделить предполагаемые компоненты на макете или скриншоте разными цветами.
   - подписать название каждого компонента.
   - использовать это разбиение как основу для структуры React-компонентов.
   - положить полученное изображение рядом `App.tsx`.
9. Покрыть компонент `More about ...` тестами: проверить корректное отображение на странице и показывает нужный текст/описание для выбранной валютной пары. Дополнительные тесты на другие компоненты приветствуются.

- Основной фокус — структура компонентов, читаемость и переиспользуемость.

### Что сдаем

- Ссылку на репозиторий.
- Рабочий код первого этапа.
- Cкриншот с визуальным разбиением на компоненты: разные цвета для разных компонентов и подписи с их названиями.
