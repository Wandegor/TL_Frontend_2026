## Домашнее задание 5: Сохраненные фильтры и `useSyncExternalStore`

### Цель

Доработать конвертер из четвертой домашки: добавить сохранение выбранных валютных пар в `localStorage`, восстановление фильтров при повторном открытии приложения и синхронизацию React с внешним хранилищем через `useSyncExternalStore`.

Основной фокус задания - корректная работа с внешним хранилищем: подписка на изменения, валидация сохраненных данных, ограничение количества фильтров и проверка валютных пар по актуальному списку валют от API.

### Что нужно реализовать

#### Сохранение фильтров

1. Добавить в интерфейс кнопки `Save Filter` и `Clear Filter`.
2. По нажатию на `Save Filter` сохранять текущую валютную пару из селектов.
3. Сохраненные пары отображать в виде горизонтального списка.
4. Каждый элемент списка должен однозначно показывать обе валюты пары, например `PLN/CAD`.
5. По нажатию на сохраненную пару она становится текущей:
   - значения обоих селектов обновляются;
   - данные конвертера и графика загружаются для выбранной пары.
6. Максимальное количество сохраненных пар - `5`.
7. Если при добавлении новой пары в списке уже максимальное количество элементов, удалить первый, самый старый фильтр, и добавить новый в конец списка.
8. По нажатию на `Clear Filter` удалить все сохраненные пары из интерфейса и `localStorage`.
9. Сохранять порядок фильтров: от самого старого к самому новому.
10. Все фильтры должны быть уникальными.

#### Работа с `localStorage`

1. Все сохраненные валютные пары должны храниться в `localStorage` под одним постоянным ключом.
2. Для чтения данных из `localStorage` и подписки на их изменения обязательно использовать `useSyncExternalStore`.

#### Восстановление и валидация

1. При открытии приложения восстановить сохраненные пары из `localStorage`.
2. Чтение сохраненных данных должно быть безопасным. Приложение не должно падать, если данные в localStorage невалидные. Если данные в localeStorage невалидные, то нужно приводить их в валидное состояние, если это возможно.
3. После загрузки списка валют от API проверить каждую фильтр:
   - обе валюты есть в актуальном списке API - показать пару в списке;
   - хотя бы одной валюты нет в списке API - удалить пару.
7. Ошибка загрузки списка валют не должна очищать сохраненные фильтры.

### UI

1. Кнопки `Save Filter` и `Clear Filter` должны быть встроены в текущий экран конвертера.
2. Список фильтров расположить горизонтально. Если элементы не помещаются на мобильном экране, допускается горизонтальный скролл или перенос строк без выхода за пределы контейнера.

### Тесты

Минимальный набор тестов:

- добавление текущей валютной пары по нажатию на `Save Filter`;
- отображение сохраненных пар в правильном порядке;
- ограничение списка пятью элементами: при добавлении шестой пары удаляется первая, а новая появляется в конце;
- запись сохраненных пар в `localStorage`;
- восстановление пар из `localStorage` при инициализации;
- выбор сохраненной пары и обновление текущих селектов;
- очистка списка и `localStorage` по нажатию на `Clear Filter`.

В тестах необходимо очищать или подменять `localStorage` между сценариями, чтобы тесты не зависели друг от друга.
